# Confabra

A confabulation-resistant synthetic corpus generator for customer intelligence evaluation. Currently in design phase.

When complete, Confabra will generate multi-month, multi-channel customer engagement corpora — support conversations, sales touchpoints, CS check-ins, onboarding interactions — with cross-artifact consistency guaranteed by a deterministic state machine. LLMs generate only surface prose constrained by validated state.

The architecture adapts the physics-cognition pattern from [OrgForge](https://github.com/aeriesec/orgforge) to the customer intelligence domain. Broader eval methodology informed by [BrainBench](https://github.com/garrytan/gbrain-evals).

## Status

Design phase. Implementation extracts from a private workstream once it has been validated against the broader eval harness it was built for. This README will be replaced when the implementation lands.
