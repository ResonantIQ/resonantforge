# Model Configuration Note

**Model configuration:** By default, ResonantForge uses `claude-haiku-4-5-20251001`. To use a different model, set the `RFORGE_MODEL` environment variable:

```
RFORGE_MODEL=claude-haiku-4-5-20251001 rforge generate ...
```
